# 🎙️ MOJI-OKO（モジオコ）— 動画・音声の文字起こし＆AI要約（v2.1・旧名: 文字起こしするちゃん）

音声・動画ファイルをアップロードするだけで、文字起こし＋要約・整形をして
コピー・txt保存、または**あなたのGoogleドライブ**へスプレッドシートで保存できるツールです。
APIキーの設定は不要。配られた**URL**と**ライセンスキー**だけで使えます（Windows・Mac・スマホ共通）。

## 使い方（受講生向け）

Windows・Mac・スマホのブラウザでそのまま動きます（インストール不要）。

1. 配布されたURLを開き、**ライセンスキー**（`MOJI-XXXX-XXXX-XXXX`）を入力して「はじめる」
   ※一度入力すれば、同じブラウザでは次回から自動で入れます。キーは1人1つ。他の人に渡さないでください
2. MP3 / M4A / WAV / MP4 / MOV / WEBM のファイルをドラッグ＆ドロップ（最大2GB・3時間程度までOK）
   ※MOVはMacのQuickTime録画・iPhoneの動画がそのまま使えます
   ※動画は**音声だけをブラウザ内で抜き出して**送るので、2GBの動画でも送信量は数十MBです
3. 必要なら「**内容のヒント**」に講座名・登場人物・よく出る用語を書く（固有名詞の精度が上がります）
4. 「**文字起こしを開始**」を押して待つ（3時間の動画で10分前後。タブは閉じないでください）
   - 万一途中で失敗したり閉じてしまっても、同じファイルをもう一度開始すれば**終わった区間は飛ばして続きから**再開します
5. 結果が2つのタブで表示されます
   - **文字起こし**: 発言そのまま（オプションでタイムスタンプ付き）
   - **要約・整形**: 全体の要約と、読みやすく整えたテキスト
6. 結果は「コピー」「txt保存」でそのまま持ち出せます
7. 「**Googleドライブに保存**」を押すと、Googleのログイン画面が開き（初回のみ）、
   あなたのドライブの「MOJI-OKO」フォルダに
   スプレッドシート（シート1: 文字起こし ／ シート2: 要約・整形）が作られます
   - 保存し忘れて閉じても、次回開いたときに「前回の結果」から復元できます

## 辞書機能（チームで賢く育てる）

固有名詞などが間違って文字起こしされたら:

1. 結果画面でテキストを直接修正する
2. 「**📖 修正を辞書に学習**」を押す → 直した単語が自動で検出されます
3. 「チーム辞書に登録」を押すと、**次回からチーム全員の文字起こしで自動修正**されます

「チーム辞書」タブから、手動での登録・編集もできます。
（書式の例: 表記「クレアカ」／読み「くれあか」／誤認識例「クレア化|暮れ赤」）

## 管理者の方へ

初回セットアップ手順は [docs/SETUP.md](docs/SETUP.md) を見てください。

### ライセンスキーの管理（辞書スプレッドシートの「ライセンス」タブ）

| やりたいこと | 操作 |
|---|---|
| キーを発行する | B列に名前を書く → GASエディタで関数 `issueLicenseKeys` を実行 → A列にキーが入る |
| 利用を止める | C列の状態を「停止」に書き換える（5分以内に使えなくなります） |
| 期限を付ける | D列に日付（例: 2026/12/31）。その日の終わりまで使えます。空欄なら無期限 |
| 使いすぎを防ぐ | E列に月の上限（分）。空欄なら無制限。G列に今月の利用分数が自動で入ります |
| 誰がいつ使ったか見る | 「利用ログ」タブ（日時・名前・キー末尾4桁・操作・分） |

照合はすべてサーバー（GAS）側で行うので、画面を細工してもキー無しでは文字起こし・辞書とも動きません。
v2からの更新なら、`gas/Code.gs` を貼り直して新バージョンでデプロイし、フロントを push し直すだけです（config.js はそのまま使えます）。
**更新後はキーが無いと誰も使えなくなる**ので、先に自分用のキーを発行してください。

## v2で変わったこと

| | v1 | v2 |
|---|---|---|
| 送信するデータ | ファイル丸ごと（動画2GBなら2GB） | 音声だけを15分ずつ切り出して送信（動画でも1分≒1MB） |
| 1時間超の動画 | Geminiの入力上限に当たり失敗 | 問題なし（区間ごとに独立して処理） |
| 区間のつなぎ目 | LLMに「重複しないで」と依頼 | 前後30秒ののりしろ＋タイムスタンプと本文照合で機械的に結合 |
| 精度 | temperature既定（1.0） | 低temperature・思考オフ・出力上限明示・安全フィルタ緩和・「内容のヒント」注入 |
| 途中で失敗 | 最初からやり直し | 終わった区間はブラウザに保存、続きから再開。スマホのスリープも抑止 |
| 所要時間の目安（3時間） | 20〜30分 | 10分前後（音声だけ送るため、アップロードもGemini側の処理も短い） |
| コスト（3時間の動画） | 区間ごとに全体を入力するため高い | 音声を1回分だけ入力。数十円程度 |

## 技術構成

- フロントエンド: 静的HTML + ES Modules（ビルドなし）、GitHub Pagesでホスティング
  - `js/media-split.js`: MP3はフレーム境界、MP4/M4A/MOVはAACトラック抽出（ADTS化）、WAVはPCM切り出しで、デコードせずに音声を分割
  - `js/merge.js`: 区間ごとの結果をタイムスタンプ＋本文照合で結合
  - `js/storage.js`: 途中経過・前回結果・ヒントを localStorage に保持
- バックエンド: Google Apps Script（Gemini APIキーはスクリプトプロパティに格納し、クライアントへは渡さない）
- 文字起こし: Gemini API Files API（ブラウザからGeminiへ直接アップロード）
- 利用者の認証: 1人1つのライセンスキー。GASが全リクエストで台帳（スプレッドシート）と照合
- Drive保存（任意）: 保存ボタンを押したときだけ Google Identity Services でログイン（スコープは `drive.file` のみ）。
  `OAUTH_CLIENT_ID` を空にすると保存ボタンごと非表示になり、GCPの設定も不要
- チーム辞書: 管理者のスプレッドシートにGAS経由で読み書き
